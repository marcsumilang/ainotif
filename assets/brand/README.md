# NotifAi brand assets

## Source artwork

- `notifai-mark.svg` is the transparent shield and N monogram.
- `notifai-logo.svg` is the horizontal wordmark for web and documents.
- Web exports live in `web/public/`; Android uses adaptive vector resources and PNG density exports.

## Colors

- Forest: `#163300`
- Spruce: `#235414`
- Signal lime: `#9FE870`
- Paper: `#F5F8F1`

The mark keeps a clear outline and a single bold N so it stays legible at launcher-icon sizes. Store icon artwork uses a square, full-bleed background; Google Play applies its own icon mask.
